# River Algorithm — Frontend

React + TypeScript + Vite interface for the River Algorithm hackathon MVP.

The frontend provides dedicated experiences for:

- recyclers
- collection-point operators
- companies retiring REC

Main flows include recycling registration, operator verification, impact
dashboard, REC balance and Burn-to-Certificate visualization.

## Run locally

```bash
npm install
npm run dev
```

Default development URL:

```text
http://localhost:5173
```

The frontend expects the API at:

```text
http://localhost:3333/api/v1
```

The hackathon MVP currently uses Solana localnet.
