# Next Milestones

The hackathon MVP is already functional end-to-end on Solana localnet.

Implemented:

- Proof of Recycling on Solana
- program-controlled REC SPL mint
- unique proof PDAs
- ImpactPool accounting
- Burn-to-Certificate
- immutable certificate PDAs
- recycler, operator and company flows
- JWT role-based authentication
- PostgreSQL persistence
- React frontend
